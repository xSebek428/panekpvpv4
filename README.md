# PvP Menu (Fabric 1.21.4, Java 21)

Budowanie:
1. Otwórz folder w IntelliJ IDEA (Gradle zsynchronizuje się sam) albo wykonaj `gradle wrapper --gradle-version 8.12`.
2. `./gradlew build` -> gotowy plik `build/libs/pvpmenu-1.0.0.jar`.
3. Wrzuć .jar do `.minecraft/mods` razem z Fabric API 0.119.2+1.21.4.

Otwieranie menu: klawisz X (zmienisz w Sterowanie -> PvP Menu).
Konfiguracja: `.minecraft/config/pvpmenu.json`.
